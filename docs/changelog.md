# 更新日志

## v1.2.4
- Feature：优化了客户端下载卡片逻辑，当对应下载链接为空时不再显示下载图标；新增 鸿蒙客户端 下载按钮。
- Fix：修复了 ProfilePage 组件 CSS 导致的高亮显示异常问题。
- Chore：调整了 Landing Page 的网格布局。

## v1.2.3
- Fix：修复了主页轮播图指示器的异常屏幕聚焦。
- Fix：修复了主页 SVG 图标在暗色下的显示。

## v1.2.2
- Fix：修复了修改密码模态框的回车键提交。
- Chore：更新了演示站。

## v1.2.1
- 优化 Landing Page 排版结构，已将文案与图标配置迁移至 public/landingpage-test.json，支持用户自行修改与定制着陆页内容。
- 新增流量重置按钮：当流量使用率超过 80% 时，将自动显示流量重置入口，方便用户及时管理用量。
- 修复一些图标错误。

## v1.2.0
- 重构套餐选择页面，优化移动端展示与交互体验。
- 知识库文本渲染器新增内链样式支持。
- 注册页面支持从 URL 中自动获取邀请码。
- 新增注册域名白名单功能，提升注册安全性与可控性。
- 修复因 DaisyUI 的 focus 机制导致下拉菜单不显示但仍可点击的问题。
- 修复在注册与找回密码页面中，按下 Enter 键会意外触发请求的问题。
- 优化邀请链接复制逻辑，确保复制的链接正确包含邀请码。

## v1.1.0 
- 全面支持三端系统：V2Board / XBoard / XiaoBoard。
- 新增 XiaoBoard 下的充值功能。
- 新增自动续费功能，提升订阅管理体验。
- 完善三端兑换码功能的统一适配。
- 适配佣金兑换记录展示与管理。
- 新增 XiaoBoard 的 Google 人机验证器支持。
- 修复因 DaisyUI 的 focus 机制导致下拉菜单不显示但仍可点击的问题。
- 修复在注册与找回密码页面中，按下 Enter 键会意外触发请求的问题。
- 优化邀请链接复制逻辑，确保复制的链接正确包含邀请码。

## v1.0.0

- 实现注册和忘记密码页面的两步验证流程。

- 新增兑换码页面开关功能。
- 修复验证器展示逻辑问题。

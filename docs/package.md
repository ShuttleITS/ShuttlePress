# 主题打包
## [获取主题包](https://pac.xiamii.com)
> 该打包机面向购买用户，用于在线生成主题包。首次登录后需绑定机场名称并填写配置，生成的前端包会锁定到用户的机场信息。

## 机场名称锁定

- 首次登录打包机，在主页输入机场名称后即锁定，用户不可再次修改。
- 前端构建页面会从已绑定的机场名称中读取该字段，无需重复输入。

## 打包流程

1) 登录打包机，首次输入机场名称（锁定）。
2) 在构建页选中模板后填写构建表单。
3) 点击「开始构建」后，会跳转到主页的构建队列等待；构建完成后自动跳转到构建下载页面，下载已构建的主题包（React+TS 静态前端）。
4) 将下载的主题包部署到你的前端域名。

## 构建表单字段
**站点信息**

| 字段 | 说明 |
| --- | --- |
| 站点名称 | 已在首页设置，不可修改（如需更改请联系管理员）。 |
| 面板类型 | 选择正确的后端类型，不同后端功能和接口会有区别。 |
| 着陆页开关 | 选择是否打开着陆页，着陆页内容可在静态主题下的 `landingpaeg-texts.json` 中配置。 |
| 站点 Logo | 支持根目录下的文件路径（如 `/logo.png`）或外部 URL。 |
| 登陆页背景 | 支持根目录下的文件路径（如 `/car.png`）或外部 URL。 |
| 前端域名 | 用于约束前端访问，最多 4 个，以逗号分隔，需填写完整域名（含协议可选，但域名必须完整）。 |
| 后端 API 地址 | 指向机场后端，默认 `/api/v1/`，静态部署不需要修改，反代时连接到真实后端即可，severless 部署指向中间件 worker 地址。 |

**苹果账号分享页**

| 字段 | 说明 |
| --- | --- |
| Apple Id Share（苹果账户分享） | 如需开启，先打开 toggle。 |
| Apple Id Share API 地址 | 默认 `/idhub-api/`如需serverless部署和后端API一样处理。 |
| IDHub API Key | 如开启分享页则必填。 |

**客户端下载**

| 字段 | 说明 |
| --- | --- |
| 客户端下载链接 | 填写 OSS 或下载直链，供客户下载客户端，留空则不显示响应下载按钮。 |



## 注意事项

- 机场名称一旦锁定不可修改，如需调整请联系管理员重置。
- 前端域名必须为完整域名，最多 4 个，逗号分隔；域名外的空格请去除。
- 默认 API 路径 `/api/v1/` 和 `/idhub-api/` 可按后端路由实际情况调整。
- 如需前后端分离部署，后端 API 地址与 IDHub API 地址请保持默认路径（`/api/v1/`、`/idhub-api/`），避免因路径差异导致跨域或路由 404。
- 额度限制：每个用户每日 2 次构建、5 次下载，合理安排构建次数，避免超额。
